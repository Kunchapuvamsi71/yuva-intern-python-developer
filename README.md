# YuvaIntern Python Developer Internship — Task 1

## Project
**Fundamentals and Setup: Hello World**

This beginner project verifies that Python code can be saved and executed. It prints a greeting and identifies the first internship task.

## Requirements
- Python 3.10 or later (Python 3.x should work)
- Any text editor or IDE, such as VS Code
- Git and a GitHub account for version control and hosting

## Run the program
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python hello_world.py
```

On some systems, use `python3 hello_world.py`.

## Expected output
```text
Hello, World!
Welcome to my Python Developer Internship!
Task 1: Fundamentals and Setup
```

## Files
- `hello_world.py` — Python entry-point program.
- `README.md` — project instructions and overview.
- `TASK1_REPORT.docx` — task report for the internship portal.
- `.gitignore` — common generated files excluded from version control.

## Learning outcomes
- Recognize a Python source file and the program entry point.
- Use `print()` to display output.
- Run a Python script from a terminal.
- Understand the purpose of Git and GitHub for tracking and sharing code.
